# Synthetic evaluation results

80 hand-labelled synthetic examples (50 original and 30 Arduino/document review additions). The detector was not changed in response to this evaluation. This is a small, developer-authored challenge set, not independent or real-world accuracy evidence.

| Profile | Exact-span precision | Exact-span recall | Exact redacted examples | Extra spans | Missed spans |
| --- | --- | --- | --- | --- | --- |
| strict | 89.8% | 86.9% | 66/80 (82.5%) | 6 | 8 |
| balanced | 89.5% | 83.6% | 64/80 (80.0%) | 6 | 10 |

Expected spans were authored manually, not generated by the scanner. Exact-span matching requires both boundaries to match; over-redaction can count as both an extra and a missed span. Exact output compares all detections redacted against all labelled spans redacted, before user decisions. Both profiles are measured against the same desired-review labels, including some patterns Balanced deliberately omits.

The set includes unlabelled secrets, unsupported obfuscation and deliberately public placeholders/contact information. Some false positives are the current conservative policy working as designed, but still create user review work. Results do not establish performance on a representative population. Read evaluation-results.json for every mismatch by example ID. No external/private dataset was used.
