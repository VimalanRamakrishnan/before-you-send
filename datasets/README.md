# Synthetic dataset v1

20 development examples and 50 evaluation examples, authored for this project using fictional values. No third-party corpus, real credential, private personal record or external dataset download is included. All examples are intended for testing only.

Each JSONL record contains an ID, category, input text, expected spans and a synthetic flag. Span offsets are half-open UTF-16 indices into the original text, matching JavaScript's string indexing. Empty expected arrays mean no review span is desired in that example's stated context. Explicitly public placeholders/contact information are included as negative/context cases.

Labels come from manually placed annotation markers in `scripts/create-dataset.py`; they are not generated by the detector. The evaluator checks exact boundaries and full redacted output. Category labels describe the example rather than requiring an exact match to the scanner's UI category. Expected output uses independently applied labelled spans. The same target labels are used for both profiles to expose coverage differences.

The development split is for development examples. The evaluation split was not used to tune detection against its labels. However, the same developer authored both with knowledge of the scanner and its earlier tests. This is not a blinded, independent, representative or statistically rigorous benchmark. It includes deliberate unsupported cases and conservative-policy false positives. Do not advertise its figures as real-world accuracy.

Run `node scripts/evaluate.cjs` from the project root to regenerate the result JSON, Markdown report and bundled extension evaluation page. Do not silently remove failed examples, derive labels from current scanner output, or tune repeatedly against this evaluation while continuing to call it held out. New real-world claims need a separate independently labelled dataset and a defined target population.
