Labels were manually authored. Both profiles were scored against the same target spans. A boundary mismatch counts as an extra span and a missed span. Exact redaction compares the entire output with the manually labelled output, before user decisions.

The set deliberately includes unsupported phrasing, obfuscated text and public placeholders. It was created by the developer with knowledge of the scanner, so it is not an independent benchmark. The detector was not tuned against these results.

Source examples, mismatch details and the evaluation script are included in the project ZIP, outside the installed extension folder.
