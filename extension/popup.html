What this check covers
Passwords, selected API-key formats, private keys, authentication headers, session cookies, URL credentials and sensitive URL parameters. Also checks contact details, labelled personal information, card-like numbers and IBAN checksums. Strict adds opaque-string, IP-address, obfuscated-email and selected identity-number heuristics.
Pattern checks can miss sensitive details and flag harmless text. No findings does not mean a message is safe. No validity checks are sent to providers. Names, addresses, identifiers and encoded secrets are not universally recognised. Only text and code files explicitly imported here are read. PDF and DOCX imports review extracted text only, not images, attachments or all hidden content; it does not block Send buttons.
Checks run inside this window. No server, analytics, saved history, or automatic clipboard reading. Copying puts the redacted text on your system clipboard, where other software may access it.
